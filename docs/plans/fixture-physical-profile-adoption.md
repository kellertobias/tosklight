# Representative fixture physical profile adoption (TL-545)

This ledger records the package-only adoption from the TL-555 foundation on branch `codex/intention-profile-adoption`. It is source and validation evidence, not a claim of measured color matching, verified physical pose, live Stage activation, or Fixture Library editor acceptance. The seven changed archives are regular immutable fixture packages. Their old mode, head, channel and function identities, mode order, DMX widths, defaults, Highlight values and non-JSON artwork bytes were compared against `HEAD` and preserved.

## Source checks

- **Cameo ROOT PAR 6:** Manufacturer [ROOT PAR 6 user manual](https://adamhall.s3.amazonaws.com/media/MARKEN/CAMEO/CLROOTPAR6WH/CLROOTPAR6WH_Cameo_Users_Manual_EN_DE_FR_ES_PL_IT.pdf), English DMX table on PDF page 172 (zero-based page 171), D7CH red, green, blue, white, amber and UV at raw 0–255. The package's existing chart D003982 / firmware v1.3+ note remains. The source names UV but does not measure its visible output.
- **Cameo AURO SPOT Z300:** Manufacturer [DMX Control Table D002965](https://adamhall.s3.amazonaws.com/media/MARKEN/CAMEO/CLASZ300/CLASZ300_Cameo_DMX_Control_Table_EN.pdf), PDF page 1 for wheel ranges 0–53, pages 3 and 5 for Zoom/Focus. The [manufacturer product page](https://www.cameolight.com/en/solutions/dj-musicians/moving-lights/moving-heads/20393/auro-spot-z300) says 10–25° Zoom and selectable 540°/630° Pan, 270° Tilt; the [user manual](https://www.cameolight.com/en/downloads/file/id/283926164), printed page 16/PDF page 15, says 10–20° beam angle and printed page 11/PDF page 11 gives the Pan setting. The conflict is recorded as `unknown` physical mapping quality; the old 10–25° endpoints are retained pending clarification.
- **Martin ELP CL / WW:** [ELP CL product/manual download page](https://www.martin.com/en-US/products/elp-cl) lists 91 RGBAL emitters and English user manual revision F (Sep 2023). [ELP WW product/manual download page](https://www.martin.com/en-US/products/elp-ww) lists English user manual revision F (Sep 2023). Each package also retains its prior exact guide URL and mode transcription note. These sources establish source type and control topology, not per-emitter XYZ/SPD.
- **ETC Lustr:** [Source Four LED Series 2 documentation](https://www.etcconnect.com/Products/Entertainment-Fixtures/Source-Four-LED-Series-2/Documentation.aspx), Source Four LED Profile v1.8.2 User Manual revision B (Feb 2024). The shipped package's original v1.6.0 transcription and Direct channel identity remain. The current documentation is evidence for family/manual identity; it is not a new photometric calibration.
- **Clay Paky Stage Zoom 1200 / SV:** [Manufacturer-authored Stage Zoom manual mirrored by Soundevent](https://www.soundevent.de/media/formulare/Manual_stage_zoom_1200_sv.pdf), printed page 9/PDF page 9 channel assignments: Pan 5, Tilt 6, Pan Fine 18, Tilt Fine 19, with the fine-control option on printed page 10/PDF page 10. Existing package notes retain the distinct historical wheel-table repair and [non-SV](https://www.manualsdir.com/manuals/585479/clay-paky-stage-zoom-1200-hmi-1200w_s.html) / [SV](https://www.manualsdir.com/manuals/585480/clay-paky-stage-zoom-1200-sv-hmi-1200w_s.html) manual references. This source proves 16-bit channel composition, not physical angular degrees. The function raw domain repair does not reinterpret percent as degrees.

## Explicitly unopted representatives

- **JBLED A7:** Four modes retain the original profile revision 4. The [JBLED A7 manual](https://www.jb-lighting.de/download/Handbuch/JBLED_A7_Manual.pdf), printed page 31/PDF page 31, says wheel raw 0–1 enables RGB and CTC combines with wheel or RGB. The existing `fixture.control` channel contains white-balance states and the 240–247 Reset function. Color recipe validation must exclude Reset; it currently cannot express complete safe Color classification for this mixed channel without changing function semantics. Existing 430°/300° channel travel also conflicts with old 540°/270° artwork motion. No mechanical zero/pivot is certified.
- **GLP JDC1 and ROBE Robin 600X LEDWash:** Their package revisions remain 3. Source-backed branch-specific global/segment optical effects and actual emitter geometry are missing. A JDC1 plate RGB path must not treat white beam segments as the same source. A ROBE zone path must include shared CTC/wheel only where it affects that zone. No copied global approximation is shipped.
- **Dual-wheel and velocity-only reference fixtures:** Remain synthetic test-contract cases in TL-555; no invented manufacturer package was added here.
