This folder is a portable ToskLight installation.

While this file is here, the application keeps its shows, desk database, extensions and logs in
the "data" folder beside it instead of your user profile. ToskLight Desk also keeps its browser
cache and its Stage renderer's preferences and snapshots there, so the Desk leaves nothing behind
on the computer. Move or copy the whole folder to take everything along; delete the folder to
remove it. ToskLight Architect's browser cache still lives in your profile.

Delete this file to make the application use the per-user application data folder instead.
