ToskLight for Windows - first start
===================================

The bundle contains ToskLight both as installers and as portable folders.

Portable (no installer, no administrator rights)
------------------------------------------------

1. Copy the "tosklight-desk-windows_amd64" folder anywhere: a show laptop, another drive, or a USB
   stick. ToskLight Architect ("tosklight-architect-windows_amd64") works the same way.
2. Open the folder and start ToskLight.exe.
3. Windows SmartScreen may warn that the application is unrecognised, because these testing builds
   are not yet code-signed. Choose "More info", check that the archive came from the expected
   GitHub release, then "Run anyway".

The folder contains portable.txt, so ToskLight keeps its shows, database, extensions, logs
(data\light-headless.log), browser cache and Stage renderer settings in a "data" folder beside
ToskLight.exe instead of your user profile; deleting the folder removes everything. Delete portable.txt to make ToskLight use %APPDATA%\de.tokenet.light instead.

Nothing needs to be installed first:

- No Visual C++ redistributable is needed; the executables carry their C runtime.
- ToskLight uses the Microsoft Edge WebView2 Runtime that Windows 11 and current Windows 10 already
  include. It is not bundled in the folder. If it is missing, ToskLight shows a message and closes;
  install the Evergreen WebView2 Runtime from
  https://developer.microsoft.com/microsoft-edge/webview2/ and start ToskLight.exe again.
- ToskLight Architect keeps its WebView2 browser cache under %LOCALAPPDATA%.

Installed
---------

tosklight-desk-windows_amd64-setup.exe and tosklight-media-windows_amd64-setup.exe install per user
under %LOCALAPPDATA%\Programs without administrator rights and add Start menu shortcuts.

Verify downloads against report-checksums.txt before running them.
