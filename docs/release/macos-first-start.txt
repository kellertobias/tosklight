ToskLight for macOS - first start
=================================

These testing builds are ad-hoc signed so macOS can verify that the application bundle is intact.
They are not yet signed with an Apple Developer ID or notarized by Apple.

After expanding the archive, first apply a fresh local ad-hoc signature on the Mac that will run
the applications. This does not need an Apple Developer identity and does not publish anything:

  cd /path/to/tosklight-bundle-macos_arm64
  bash sign-macos-apps-locally.sh

The script signs Desk, PreVIZ, and Media and verifies every completed bundle. It does not remove
the download quarantine or disable Gatekeeper.

1. Move the application you want to use to Applications.
2. In Finder, Control-click the application and choose Open.
3. Confirm Open in the dialog. If macOS instead directs you to System Settings, open Privacy &
   Security and use Open Anyway for ToskLight after checking that this archive came from the
   expected GitHub release.

Do not remove quarantine attributes. If signing or verification fails, verify the archive against
report-checksums.txt and download the newest release rather than overriding macOS security checks.
