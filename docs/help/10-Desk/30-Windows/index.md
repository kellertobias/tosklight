# Windows and Panes

Panes form a saved Desktop. Add one from an empty grid cell or **Open Window**, drag its header to move it, and open **Settings** to configure that instance. A full built-in provides temporary focused work without changing the Desktop.

Every pane has **Pane Settings** for title, position, size, and removal. Width uses 1–24 columns and height 1–18 rows. Removing a pane does not delete its show objects. Tiled panes also offer square or fixed-row/column layouts; see [Desk Interface and Windows](01-desk-interface-and-windows.md).

- [Programming and Visualization Windows](02-programming-and-visualization.md): Presets, Groups, Fixtures, Media, Stage, Channels, and Dynamics.
- [Cue and Playback Windows](03-cues-and-playbacks.md): Cuelists, Cues, Running, Macros, Timecode, and Playbacks.
- [Output and Help Windows](04-utility-and-diagnostics.md): DMX monitoring and this manual.
- [Programming Windows](06-programming-windows.md): pool symbols, Position controls, and Color spreading.
- [Channel Faders](07-channel-faders.md): direct intensity programming.
