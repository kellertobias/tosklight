# ToskLight Desk

ToskLight Desk is the lighting-control application. It owns the active Desk session, Programmer, show library, fixture patch, Groups, Presets, Cuelists, Cues, Dynamics, Playbacks, output routes, and operator Desktops.

Work through the Desk manual in this order:

1. [Show Setup and Patching](10-Show-Setup/index.md) covers installation-specific Desk configuration, portable shows and revisions, fixture types and GDTF, patching, MVR exchange, and Stage placement.
2. [Programmer and Cues](20-Programmer-and-Cues/index.md) covers selection, values, Groups, Presets, the command line, recording, Update, Cuelists, Playbacks, Dynamics, Preload, Timecode, and show operation.
3. [Windows and Panes](30-Windows/index.md) identifies the complete Desk interface and explains which functions are full built-ins, reusable panes, setup workflows, modals, or separate applications.

Desk configuration and show data are deliberately separate. Users, screens, local input devices, and installation settings remain with the Desk. Fixtures, patch, Groups, Presets, Cues, Dynamics, Playbacks, and other show objects travel in the portable `.show` file.

The exact keypad and command grammar is the [Command Line Reference](20-Programmer-and-Cues/01-command-line.md). Other chapters explain the operator workflow and link back to that reference rather than defining competing commands.
