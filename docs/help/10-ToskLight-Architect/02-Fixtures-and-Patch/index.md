# Fixture library and patch

Build and patch the rig in either Architect or Control. Both use the same fixture profiles and patch sheet. Start in Architect when planning the rig, or open **Show > Show Patch** in Control to work directly on the production show.

- [Choose and import fixture types](01-fixture-library.md).
- [Add fixtures and set addresses](02-add-and-patch-fixtures.md).
- [Import a CSV patch list](03-import-csv.md).
- [Choose heads, splits, or multi-patch](04-heads-splits-and-multipatch.md).
- [Replace a physical fixture in Control](05-replace-a-fixture.md).
- [Inspect and configure the patch](06-patch-settings.md).
- [Discover and patch Pixel outputs](07-media-server-connections.md).
- [Edit the Architect patch views](08-architect-patch-views.md).

For a fixture that needs a new or corrected profile, use [Create and revise fixture profiles](10-edit-fixture-profiles.md). Calibration belongs either to the profile or to one installed unit; the linked chapters explain which to use.
