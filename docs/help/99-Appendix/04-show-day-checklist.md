# Show-day checklist

Check the production machine, network, fixtures, and displays together before opening doors. A correct preview or Programmer value does not establish that the intended physical output is working.

- Confirm the active show, playback page, screens, output routes, and universe destinations.
- Save a named revision and confirm that the intended show can be reopened.
- Clear temporary Programmer, Highlight, Freeze, FixAT, and Preload states that are not part of the show.
- Run each required Cuelist, Macro, Timecode, Dynamic, and release path. Check transitions with the Programmer cleared.
- Check representative real fixtures for intensity, color, focus, and movement.
- Check Pixel's physical displays, audio, content slots, and previews on the production machine.
- Confirm the Visualizer has the intended scene and matching live DMX universes.
- Keep recoverable show copies and the PDF or offline HTML manual with the release.
