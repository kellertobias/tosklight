# Development and Future Features

Design notes, unresolved product questions, the canonical test-bench catalog, and future feature plans live here. These topics describe development work and are not operator instructions.

The current operator-manual completeness contract is [Help Coverage](02-help-coverage.md). Planned behavior must be labeled as planned and must not be described as available operation.

[Developing Native Hardware Extensions](05-native-extension-development.md) is the standalone
implementer handoff for vendor control surfaces, feedback hardware, telemetry sources, device
actions, and timecode sources.
