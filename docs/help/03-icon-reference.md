# Icon Reference

ToskLight includes an original single-color icon family for lighting-desk controls, show content, and fixture types. Every SVG has a transparent background and renders black by default. Inline consumers can change the CSS `color` of the shared `tosklight-icon` class.

The following generated contact sheets are grouped exactly like the SVG source catalog. They render the scale-stable filled-geometry `.expanded.svg` derivatives; each filename below an icon identifies the corresponding editable source SVG.
