# ToskLight Control

![ToskLight Control application icon](../assets/branding/tosklight-control.png)

ToskLight Control programs and runs the show. Use its Programmer to build looks, store them as Cues, assign playbacks, and send DMX to the rig. Its lightweight Stage shows Live or Preload fixture state; launch the separate Architect Visualizer for rendered lighting.

Open a rig prepared in Architect, or patch fixtures directly in Control using the same [fixture and patch tools](../10-ToskLight-Architect/02-Fixtures-and-Patch/02-add-and-patch-fixtures.md). Architect is optional. Add Pixel when the show needs media playback or mapped output.

Start with [desk and show setup](10-Show-Setup/index.md), then [programming and show operation](20-Programmer-and-Cues/index.md). The [window reference](30-Windows/index.md) covers saved Desktops, panes, and display settings.

The [programmer command line](20-Programmer-and-Cues/01-command-line.md) is the desk's operator command language. You can combine it with touch, keyboard shortcuts, encoders, and attached controls. The [keypad reference](../99-Appendix/00-keypad-and-keyboard.md) lists every key and shortcut.

Fixtures, patch, Groups, Presets, Cues, Dynamics, and Playbacks travel in the `.show` file. Screen layouts, local devices, and installation settings stay with the desk.
