# Programming and viewing windows

Choose the surface that fits the task. Every programming surface uses the desk's shared Programmer selection and values.

- [Fixture Sheet](05-fixture-sheet.md) shows fixture values, sources, heads, filters, and Freeze state.
- [Group and Preset pools](10-pools.md) hold selections and reusable values.
- [Stage and Visualizer](08-stage.md) show Live or Preload output and support spatial selection.
- [Media](09-media.md) selects media layers, files, masks, and internal audio.
- [Channel faders](07-channel-faders.md) provide direct level control.
- [Dynamics](../20-Programmer-and-Cues/09-dynamics.md) animates fixture attributes.

## Visualization

The Visualization pane monitors raw DMX or resolved fixture attributes without changing output.
Add rows and text, number, bar, or graph widgets in **Pane Settings → Visualization**. Configure the
source, range, scale, and display style; unavailable sources are identified rather than shown as
live values.
