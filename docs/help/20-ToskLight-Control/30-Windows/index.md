# Windows and panes

A Desktop stores an arrangement of panes. Add one from an empty grid cell or **Open Window**, move it by its header, and open **Settings** to configure that instance.

Every pane has common **Pane Settings** for its title, position, size, and removal. **Grid width** uses 1-24 columns and **Grid height** uses 1-18 rows. **Remove pane** removes the view without deleting show data. The same pane type can appear several times with different settings. Tiled panes offer square or fixed-row/column layouts; see [Desk interface](01-desk-interface-and-windows.md#desktops-and-panes).

Use a full built-in for temporary work and a pane for a saved view. [Desk interface and windows](01-desk-interface-and-windows.md) covers the dock, command line, Desktops, multiple screens, and settings ownership.
