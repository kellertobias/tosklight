# Prepare Control

Load the production show, configure the desk, and check output before programming. You can build and patch the rig entirely in Control; Architect is optional.

1. [Configure the desk](01-desk-setup.md) and [screens](02-screens-and-layouts.md).
2. [Create or load a show](10-shows-revisions-and-mvr.md), including a rig prepared in Architect.
3. Open **Show > Show Patch**. Use the [shared fixture library and patch guide](../../10-ToskLight-Architect/02-Fixtures-and-Patch/index.md) to add fixtures, choose modes, set addresses, or leave fixtures unpatched.
4. [Check Stage views](13-stage-positions-and-scenery.md) and [configure DMX output](04-dmx-output.md).
5. Check [attached hardware](07-attached-hardware.md), [inputs and network control](03-inputs-extensions-and-network.md), and [recovery](05-users-sessions-and-recovery.md).

The portable `.show` file carries the rig and its programming. Screens, layouts, network bindings, and installation preferences stay with the desk. Back up both show files and desk data when moving an installation.
