__DEMO__

Professional concepts should survive a smaller budget.

Industry-standard lighting desks are excellent tools and worth every penny. But below that price point, small productions are often left with workflows that do not transfer when the venue, show, or operator grows.

ToskLight is built to bridge that gap. Start by pointing and clicking, then grow into the command line, Programmer, tracking, Groups, Presets, Cuelists, and Playbacks used by professional desks. The hours spent learning the software should remain useful on the next show and the next control surface.

Everything a live desk needs

  • Programmer and command line. Select fixtures, work with real keypad grammar, spread values, and build reusable looks.
  • Referencing and tracking. Ordered Groups, Presets, sparse tracked Cues, Preload, GO, and page-aware Playbacks.
  • Visualization. Fixture Sheet, Channels, DMX, and built-in 2D and 3D Stage views stay connected to the live desk.
  • Fixture and show exchange. Transfer fixture packages and portable SQLite show files; use MVR for venue data.
  • Output and integration. Art-Net, sACN, OSC, native extensions, timecode, attached hardware, and browser-connected operator surfaces.

Technical specifications

Show files MVR import and export, GDTF fixture support, and portable show files in SQLite format.
Output Networked DMX via Art-Net and sACN at up to 60 Hz across as many as 128 sparsely populated universes. A realistic modern-hardware workload is 4,096 or more occupied addresses.
Desktop and headless Native desktop builds support macOS on Apple Silicon, 64-bit Windows, and Linux x86_64. A headless Raspberry Pi ARM64 build serves its UI through a browser.
Starter show The included demo show is built for live and club busking. Import your fixtures, assign them to the prepared Groups, update the Presets, and you are ready for doors open.
Tracking sparse Cuelists Store only what changes while earlier values track forward automatically. Cue Only restores temporary changes, and per-value fades and delays keep complex Cuelists compact and readable.
Dynamics editor Build effects visually from familiar sine, cosine, PWM, and random waveform lanes. Touch-friendly controls make size, speed, phase, wings, ordering, and fixture targeting approachable.
Macro engine Work in progress toward full desk automation and custom user interfaces built from reusable operator actions.
Timecode / timeline playback Work in progress toward repeatable automation arranged on a timeline and driven by show timecode.

Release performance

Measured after publication using the released Linux benchmark artifact. The 1,024-fixture indicator is green at 60 Hz, yellow from 40 Hz, and red below 40 Hz. The 2,048-fixture run diagnoses the current limit without blocking the release.

__PERFORMANCE__

Standalone server

Download the server archive for your platform, unpack it, and run light-headless. The operator UI is embedded — open http://127.0.0.1:5000. Bind beyond localhost only on a trusted control network, and set LIGHT_DESK_TOKEN when you do.

For developers

ToskLight is a Rust workspace with TypeScript/React operator interfaces hosted by Tauri. Start the full desktop development path with npm run open.
